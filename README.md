# Hostel Maintenance Tracker

## Setup

1. Install PHP with the `mysqli` extension and a MariaDB server.
2. Create a MariaDB database for the application.
3. Import `database/schema.sql`, then optionally import `database/sample_data.sql`.
4. Configure the database connection in `config/db.php`.
5. Serve this directory from a PHP-enabled web server and open `index.php`.

Application pages, endpoints, and database definitions are scaffolded but not yet implemented.
